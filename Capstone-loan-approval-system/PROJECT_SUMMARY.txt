ARCHITECTURE LAYERS
================================================================================

Layer 1: Presentation    → Streamlit chatbot UI (localhost:8501)
Layer 2: Microservice    → FastAPI REST (localhost:8000)
Layer 3: Orchestration   → LangGraph state machine
Layer 4: Agents          → 4 domain-specific agents with Claude
Layer 5: Communication   → MCP servers (stdio-based)

WORKFLOW
================================================================================

1. User submits loan application via Streamlit form
2. FastAPI microservice receives application data
3. LangGraph orchestrator routes to agent pipeline
4. Profile Agent analyzes applicant (income stability, employment risk)
5. Risk Agent calculates financial metrics (DTI, credit risk)
6. Decision Agent synthesizes classification (Approved/Rejected/Review)
7. Compliance Agent logs action and generates case ID
8. Result displayed in Streamlit with color-coded decision
9. Application added to history for tracking

DECISION FACTORS
================================================================================

Classification Rules:
  - Risk Score < 35  → APPROVED (high confidence)
  - Risk Score < 60  → APPROVED (medium confidence)
  - Risk Score < 75  → MANUAL REVIEW (medium confidence)
  - Risk Score ≥ 75  → REJECTED (high confidence)

Risk Score Components:
  - Credit score risk (LOW/MEDIUM/HIGH/CRITICAL)
  - Loan amount risk (LOW/MEDIUM/HIGH/CRITICAL)
  - Debt-to-income ratio (high DTI increases risk)
  - Income stability score (low income increases risk)
  - Anomaly detection (unusual patterns increase risk)
